# Security policy

`lifecal` reads a local YAML file (using a safe loader that cannot run code) and writes a local `.ics` file. It makes no network requests.

If you find a security problem, please report it privately through [GitHub's private vulnerability reporting](https://github.com/nicoleyangcoding/life-maintenance-calendar/security/advisories/new) rather than opening a public issue. You can expect a reply within 7 days.
